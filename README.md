# EzDonut

A Minecraft base-hunting utility designed to help players locate hidden bases, analyse their surroundings, and improve their exploration workflow.

## Features

- **Base Detection** — Tools for identifying potential player-built structures.
- **World Analysis** — Examine terrain and surrounding environments.
- **Coordinate Tracking** — Keep track of interesting locations.
- **Customisable Settings** — Configure the tool to suit your preferences.
- **Performance Focused** — Designed with efficiency in mind.
- **User-Friendly Interface** — Simple controls and clear information.

## Requirements

- Minecraft version: `1.21.11`
- Loader: `Fabric`

## Installation

1. Download the latest release.
2. Follow the installation instructions for your Minecraft version and loader.
3. Launch Minecraft and configure the available settings.
4. Check the documentation for usage instructions.

## Usage

1. Join a supported world or server.
2. Open the tool's interface.
3. Configure the available detection and analysis options.
4. Explore and review the information provided.

## Configuration

Customisation options depend on the version you are using. Refer to the configuration files or in-game settings for available options.

## Compatibility

Compatibility may vary depending on your Minecraft version, mod loader, and server configuration.
